# TechCore Solutions

Professional IT Services & Computer Solutions Platform

## Overview

TechCore Solutions is a modern, fully responsive IT company website developed using Lovable and integrated with Supabase.

The platform is designed to present IT services, computer equipment, technical support, networking solutions, cybersecurity services, and customer communication through a modern and professional user experience.

## Supabase Integration

The website is connected to a Supabase database.

Customer inquiries submitted through the contact form are automatically stored in the database table:

### kontakt_poruke

Stored fields:

* id
* ime
* email
* telefon
* poruka
* created_at
